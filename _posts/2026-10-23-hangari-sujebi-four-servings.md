## 우리 집 한 그릇 요리, 수제비

쫄깃한 손반죽과 멸치 다시마 육수로 담백하고 든든하게 끓여냅니다. 기본 계량과 순서를 따라 차근차근 만들어 보세요.

![멸치 다시마 육수로 끓여 따뜻하게 담아낸 수제비]({{ '/assets/images/recipes/sujebi/finished.jpg' | relative_url }})

**분량: 4인분** · **준비 20분 · 휴지 30분 · 조리 25분**

계량 기준: 1큰술 = 15mL, 1작은술 = 5mL

## 1. 재료 한눈에 보기

![수제비 반죽과 육수, 채소를 준비한 모습]({{ '/assets/images/recipes/sujebi/ingredients.jpg' | relative_url }})

### 반죽

| 재료 | 4인분 분량 |
| --- | --- |
| 중력분 | 600g |
| 물 | 300~330mL |
| 소금 | 1작은술 |
| 식용유 | 1큰술, 선택 |

### 육수와 채소

| 재료 | 4인분 분량 |
| --- | --- |
| 물 | 2.5L |
| 국물용 멸치 | 20g |
| 다시마 | 1장 |
| 감자 | 2개 |
| 애호박 | ½개 |
| 양파 | ½개 |
| 대파 | ½대 |
| 다진 마늘 | 1큰술 |
| 국간장 | 1~2큰술 |
| 소금·후추 | 마지막 간을 맞출 만큼 |

간은 국간장으로 먼저 맞춘 뒤 소금으로 마무리합니다.

## 2. 반죽을 치대고 쉬게 하기

![볼에서 수제비 반죽을 손으로 치대는 모습]({{ '/assets/images/recipes/sujebi/dough.jpg' | relative_url }})

### ① 재료 섞기

밀가루와 소금을 섞고 물을 조금씩 부어 한 덩어리로 만듭니다.

### ② 충분히 치대기

손으로 **8~10분** 치대 표면이 매끈하고 탄력 있게 합니다.

### ③ 냉장 휴지

덮개를 씌워 **냉장고에서 30분 이상** 쉽니다. 반죽이 한결 부드러워집니다.

**반죽 상태 조절:** 질면 밀가루를 조금 더하고, 되면 물을 1큰술씩 보충하세요.

## 3. 육수에 넣고 익히기

![끓는 멸치 다시마 육수에 수제비 반죽을 얇게 떼어 넣는 모습]({{ '/assets/images/recipes/sujebi/cooking.jpg' | relative_url }})

### ① 멸치 다시마 육수

물 **2.5L**에 멸치와 다시마를 넣고 끓입니다. 끓기 시작하면 다시마를 건지고, 멸치는 **10분 더** 끓인 뒤 건집니다.

### ② 채소와 간 맞추기

감자와 양파를 넣어 **5~7분** 끓입니다. 감자가 반쯤 익으면 애호박, 다진 마늘, 국간장을 넣습니다.

### ③ 수제비 익히기

반죽을 얇게 떼어 넣습니다. 서로 붙지 않게 나누어 넣고, **떠오른 뒤 2~3분 더** 끓입니다.

대파를 넣고 소금·후추로 마지막 간을 맞춥니다.

## 4. 함께 먹기와 바지락 추가하기

김치와 함께 내면 잘 어울립니다. 바지락을 더할 때는 해감한 조개를 먼저 넣고 입이 벌어질 때까지 익히세요.
