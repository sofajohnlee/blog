고슬고슬한 케첩 볶음밥 위에 부드러운 달걀을 덮는 한 접시입니다. 종이 레시피의 재료와 분량, 조리 순서를 그대로 따라 만들 수 있도록 정리했습니다.

**분량: 4인분** · **계량 기준: 1큰술 = 15mL / 1작은술 = 5mL**

## 1. 재료 준비

### 볶음밥 주재료

| 재료 | 4인분 분량 |
| --- | --- |
| 밥 | 4공기, 약 800g |
| 닭다리살 또는 햄 | 닭다리살 300g 또는 햄 200g |
| 양파 | 1개 |
| 당근 | ½개 |
| 소금·후추 | 약간 |

### 볶음밥 양념

| 재료 | 4인분 분량 |
| --- | --- |
| 케첩 | 8큰술 |
| 진간장 | 2작은술 |
| 버터 | 20g |
| 식용유 | 2큰술 |

### 달걀 덮개

| 재료 | 4인분 분량 |
| --- | --- |
| 달걀 | 8개 |
| 우유 | 4큰술 |
| 버터 | 40g |
| 소금 | 네 꼬집 |

달걀은 **1인분씩 총 4회** 조리합니다. 1회분은 **달걀 2개 + 우유 1큰술 + 버터 10g + 소금 한 꼬집**입니다.

### 소스

| 재료 | 4인분 분량 |
| --- | --- |
| 케첩 | 6큰술 |
| 돈가스소스 | 4큰술 |
| 물 | 8큰술 |
| 버터 | 10g |
| 설탕 | 1작은술, 선택 |

## 2. 조리 전 손질

### 밥의 김 빼기

밥을 넓게 펼쳐 김을 빼 둡니다. 뜨겁고 축축한 밥은 볶을 때 쉽게 뭉칩니다.

### 재료 썰기

양파와 당근은 잘게 썹니다. 닭다리살은 1cm 크기로 썰어 준비합니다.

### 도구 꺼내기

볶음밥용 팬, 작은 코팅팬, 소스 냄비를 준비합니다. 달걀을 저을 젓가락이나 실리콘 주걱도 꺼냅니다.

## 3. 새콤하고 부드러운 소스

**불 조절: 약불 / 끓이는 시간: 2~3분**

1. **소스 재료 섞기:** 케첩 6큰술, 돈가스소스 4큰술, 물 8큰술을 작은 냄비에 넣고 약불로 2~3분 끓입니다.
2. **버터로 마무리:** 불을 끄고 버터 10g을 넣어 섞습니다. 맛을 보고 신맛이 강하면 설탕 1작은술을 추가합니다.

소스는 숟가락에서 부드럽게 흐를 정도로 맞춥니다. 걸쭉하면 물을 조금 더합니다.

## 4. 고슬고슬한 케첩 볶음밥

1. **고기와 채소 볶기:** 식용유 2큰술을 두른 팬에서 중강불로 닭고기를 충분히 익힙니다. 양파·당근을 넣고 양파가 투명해지고 팬의 물기가 없어질 때까지 볶습니다.
2. **케첩 먼저 볶기:** 재료를 한쪽으로 밀고 빈 공간에 케첩 8큰술을 넣습니다. 타지 않게 저으며 30~60초 볶아 수분을 날립니다.
3. **밥 넣고 간하기:** 밥을 넣어 덩어리를 풀고, 진간장 2작은술과 버터 20g을 섞습니다. 소금·후추로 간한 뒤 네 접시에 봉긋하게 담습니다.

**팬이 작으면 2인분씩 두 번 볶고, 재료와 양념을 절반씩 나눠 사용합니다.**

## 5. 촉촉한 달걀 덮개

**작은 코팅팬 / 중약불 / 1인분씩 총 4회**

1. **달걀 풀기:** 달걀 2개에 우유 1큰술과 소금 한 꼬집을 넣습니다. 흰자 덩어리가 거의 없어질 때까지 풉니다.
2. **부드럽게 젓기:** 팬에서 버터 10g을 녹이고 갈색이 되기 전에 달걀물을 붓습니다. 작게 원을 그리며 젓습니다.
3. **모양 잡고 덮기:** 절반 정도 굳으면 젓기를 멈추고 팬을 기울입니다. 바닥이 잡히고 달걀물이 흐르지 않으면 불을 끕니다.
4. 팬에서 달걀을 미끄러뜨려 볶음밥 위에 덮습니다. 남은 3인분도 같은 방법으로 만듭니다.

## 6. 따뜻한 한 접시 완성

따뜻한 소스를 **가장자리와 밥 주변에** 두릅니다. 취향에 따라 후추나 파슬리를 조금 뿌립니다.

## 7. 다음 조리를 위한 메모

### 밥이 질어졌다면

다음에는 밥의 김을 충분히 빼고, 채소의 물기를 날린 뒤 밥을 넣습니다.

### 달걀이 퍽퍽하다면

불을 낮추고 익힘 상태를 자주 확인합니다. 표면이 촉촉할 때 마무리합니다.

**밥의 수분과 팬의 온도가 식감을 좌우합니다.**
