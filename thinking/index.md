# 생각정리, 마인드맵으로 시작하기

머릿속에 할 일과 아이디어가 뒤섞여 있다면 **가운데에 주제를 하나 쓰고, 관련 생각을 가지처럼 펼쳐 보세요.** 마인드맵은 생각의 큰 흐름과 세부 내용을 한눈에 살펴보는 정리 방법입니다.

## 1. 마인드맵이란?

**중심 주제 → 큰 가지 → 세부 가지** 순서로 생각을 연결하는 그림입니다. 한 줄씩 길게 쓰는 대신, 관련 내용을 묶어 펼쳐 놓아 빠진 부분과 연결되는 부분을 살펴봅니다.

- **중심 주제:** 이번에 무엇을 생각할 것인가?
- **큰 가지:** 어떤 관점이나 항목으로 나눌 것인가?
- **세부 가지:** 구체적으로 무엇을 확인하거나 실행할 것인가?

예를 들어 중심에 ‘주간 업무 정리’를 쓰고, ‘목표·진행상황·문제·다음 행동’을 큰 가지로 뻗으면 업무를 정리하는 지도가 됩니다.

## 2. 언제 사용하면 좋을까요?

| 상황 | 중심에 쓸 주제 | 큰 가지 예시 |
| --- | --- | --- |
| 공부한 내용 복습 | 오늘 배운 개념 | 정의·핵심 원리·예시·헷갈린 점 |
| 보고서 초안 | 보고할 안건 | 배경·현황·쟁점·대안·요청사항 |
| 회의 준비와 정리 | 회의 목적 | 안건·의견·결정·후속 조치 |
| 선택지 비교 | 결정할 질문 | 선택지·평가 기준·장단점·확인할 정보 |
| 개인 목표 세우기 | 이번 달 목표 | 이유·필요한 자원·장애물·실천 |

처음 생각을 펼칠 때는 마인드맵을 쓰고, 일정·담당자·비용을 정확히 관리할 때는 표나 체크리스트로 옮기면 편합니다.

<h2 id="steps">3. 마인드맵 작성법 — 6단계</h2>

### ① 중심에 주제를 하나 적기

종이를 가로로 놓거나 디지털 도구의 빈 화면을 엽니다. 가운데에 **‘이번 주 업무를 어떻게 마무리할까?’**처럼 범위가 분명한 제목이나 질문을 적습니다. 주제가 너무 크면 ‘내 인생’ 대신 ‘이번 달 생활 계획’처럼 좁혀 보세요.

### ② 큰 가지를 만들기

중심에서 바깥으로 선을 뻗고 주요 항목을 적습니다. 처음에는 **3~6개 정도**로 시작해도 충분합니다. 정해진 개수에 맞추기보다 주제에 필요한 항목을 고르세요.

생각이 막히면 ‘무엇을·왜·누가·언제·어떻게’ 또는 ‘현황·문제·대안·실행’을 질문으로 사용합니다.

### ③ 세부 생각을 짧은 말로 붙이기

각 큰 가지 아래에 관련 내용을 붙입니다. ‘자료를 검토하고 문제가 있으면 담당자에게 확인해야 한다’ 대신 **‘자료 검토 → 누락 확인 → 담당자 질의’**처럼 짧은 말로 나눠 씁니다. 긴 근거나 설명은 별도 메모에 기록합니다.

### ④ 먼저 펼치고, 나중에 묶기

처음에는 떠오르는 생각을 적는 데 집중합니다. 그다음 중복 항목을 합치고, 비슷한 내용을 같은 가지로 옮기며, 빠진 관점을 추가합니다. 여러 가지에 걸친 생각은 연결선이나 같은 표시로 관계를 남깁니다.

### ⑤ 중요한 내용과 미확인 사항 표시하기

별표는 우선순위, 물음표는 추가 확인이 필요한 내용처럼 **표시의 의미를 정해 일관되게** 사용합니다. 색은 가지를 구분하는 보조 수단으로 쓰고, 글자와 기호만으로도 뜻을 알 수 있게 합니다.

특히 업무 자료에서는 ‘확인된 사실’과 ‘내 추측’을 구분하고, 근거가 되는 문서나 링크를 메모해 두세요.

### ⑥ 실행할 일로 바꾸기

지도를 완성한 뒤 지금 해야 할 일 1~3개를 고릅니다. **무엇을·누가·언제까지 할지** 표로 옮깁니다. 마인드맵을 예쁘게 완성하는 것보다 다음 행동을 분명히 하는 것이 목적입니다.

<h2 id="template">5. 바로 따라 쓰는 마인드맵 틀</h2>

종이나 메모 앱에 아래 질문을 옮긴 뒤, 답을 가지로 펼쳐 보세요.

| 위치 | 적을 내용 | 나에게 던질 질문 |
| --- | --- | --- |
| 중심 | 정리할 주제 한 가지 | 지금 무엇을 명확하게 하고 싶은가? |
| 가지 1 · 목적 | 원하는 결과 | 정리가 끝나면 무엇이 달라져야 하나? |
| 가지 2 · 현황 | 알고 있는 사실과 자료 | 현재 어디까지 진행되었나? |
| 가지 3 · 쟁점 | 문제와 모르는 점 | 무엇이 막혀 있고, 무엇을 확인해야 하나? |
| 가지 4 · 대안 | 가능한 방법 | 다른 방법은 무엇이며 장단점은 무엇인가? |
| 가지 5 · 실행 | 다음 행동 | 누가, 언제까지, 무엇을 할 것인가? |

**10분 연습:** 주제 정하기 1분 → 큰 가지 만들기 2분 → 세부 생각 펼치기 4분 → 묶고 정리하기 2분 → 다음 행동 고르기 1분.

## 6. 종이와 디지털 도구, 이렇게 사용하세요

**종이:** 가운데에 주제를 적고 선으로 가지를 연결합니다. 생각을 빠르게 펼칠 때 편하며, 큰 수정이 필요하면 새 종이에 다시 묶어 그려도 됩니다.

**디지털 도구:** 중심 주제를 만든 뒤 ‘하위 주제 추가’ 기능으로 가지를 만듭니다. 같은 수준의 생각은 ‘같은 수준 주제 추가’로 넣고, 가지를 이동해 구조를 다듬습니다. 단축키는 도구마다 다르므로 사용 중인 도구의 도움말을 확인하세요. 공유할 때는 상대방의 열람·수정 권한과 내보내기 결과를 확인합니다.

업무 자료를 외부 서비스에 입력하기 전에는 해당 자료의 공개 범위와 기관의 이용 기준을 확인하세요.

## 7. 자주 막히는 부분

| 어려움 | 바꿔 볼 방법 |
| --- | --- |
| 어디서 시작할지 모르겠음 | 중심을 질문형으로 적고 ‘무엇을·왜·어떻게’부터 시작 |
| 가지마다 긴 문장이 들어감 | 핵심 낱말로 줄이고 설명은 별도 메모로 분리 |
| 가지가 너무 많아 복잡함 | 비슷한 가지를 묶고 큰 주제는 별도 지도로 분리 |
| 예쁘게 꾸미느라 시간이 오래 걸림 | 우선 글자와 선만으로 작성하고 필요한 표시만 추가 |
| 정리했는데 행동이 달라지지 않음 | 다음 행동 1개와 기한을 정해 체크리스트로 옮기기 |

## 8. 마무리 점검

- 중심 주제가 한 가지로 분명한가요?
- 큰 가지가 주제를 이해하는 데 필요한 관점을 담고 있나요?
- 중복되거나 빠진 항목은 없나요?
- 확인된 사실과 추가 확인할 내용이 구분되나요?
- 지금 할 행동과 완료 기준을 정했나요?
