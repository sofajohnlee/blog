# 통기타, 코드부터 차근차근

코드는 여러 음을 함께 울리는 **화음**입니다. 왼손으로 줄을 누르고 오른손으로 줄을 튕기거나 쓸어 내려 반주합니다. 이 페이지는 **오른손잡이 기타·표준 튜닝** 기준으로 코드표를 읽고 기본 코드를 연습하는 입문 안내입니다.

## 1. 줄 번호와 튜닝

가장 굵고 낮은 소리가 나는 줄이 **6번 줄**, 가장 가늘고 높은 소리가 나는 줄이 **1번 줄**입니다. 표준 튜닝은 굵은 줄부터 **E–A–D–G–B–E(미–라–레–솔–시–미)**입니다.

| 줄 | 개방현 음 | 기억할 점 |
| --- | --- | --- |
| 6번 | E · 미 | 가장 굵은 줄 |
| 5번 | A · 라 | A·Am·C 코드의 시작 줄 |
| 4번 | D · 레 | D·Dm 코드의 시작 줄 |
| 3번 | G · 솔 | 가운데의 가는 쪽 줄 |
| 2번 | B · 시 | 1번 줄 바로 옆 |
| 1번 | E · 미 | 가장 가는 줄 |

**개방현**은 왼손으로 누르지 않고 울리는 줄입니다. **프렛**은 지판의 금속 막대이며, “1프렛을 누른다”는 말은 너트와 첫 번째 막대 사이에서 줄을 누른다는 뜻입니다. 누르는 손가락은 막대 바로 뒤쪽에 두되, 막대 위에 얹지는 않습니다.

## 2. 코드 이름 읽기

- **C, D, E, F, G, A, B**: 각각 도·레·미·파·솔·라·시를 근음으로 하는 메이저 코드입니다.
- **Am, Dm, Em**: ‘에이 마이너, 디 마이너, 이 마이너’로 읽습니다. 소문자 **m**은 마이너를 뜻합니다.
- **G7, A7**: ‘지 세븐, 에이 세븐’입니다. 기본 메이저 3화음에 단7도 음을 더합니다.
- **Cmaj7**: ‘씨 메이저 세븐’입니다. C7과 달리 장7도 음을 더하므로 서로 다른 코드입니다.

메이저 3화음은 **근음·장3도·완전5도**, 마이너 3화음은 **근음·단3도·완전5도**로 구성합니다. 예를 들어 C는 도·미·솔, Am는 라·도·미입니다. 여섯 줄을 치더라도 같은 음이 다른 높이로 겹칠 수 있으므로 구성음이 여섯 종류라는 뜻은 아닙니다.


### 2-1. 오선지에서 ‘3도’와 ‘5도’를 먼저 세어 보기

**‘도’는 여기서 도레미의 첫 음 ‘도(C)’라는 이름과, 두 음 사이의 간격을 세는 단위인 ‘도(度)’로 쓰입니다.** “도에서 미가 3도”라는 말은 **C와 E의 음 이름 간격이 3도**라는 뜻입니다.

간격을 셀 때는 **출발하는 음도 1로 셉니다.** 도에서 미까지는 **도(1)–레(2)–미(3)**이므로 3도이고, 도에서 솔까지는 **도(1)–레(2)–미(3)–파(4)–솔(5)**이므로 5도입니다. 코드에서 실제로 레와 파를 연주한다는 뜻은 아닙니다. 간격을 셀 때 그 음 이름을 거쳐 세는 것입니다.

#### 오선지의 줄과 칸 읽기

오선지는 아래에서 위로 갈수록 높은 음을 나타냅니다. **줄 위 → 바로 위 칸 → 그 위 줄**로 한 자리씩 이동하면 음 이름도 순서대로 올라갑니다. 아래 그림은 **높은음자리표** 기준이며, 조표와 임시표가 없는 자연음으로 설명합니다.

- 맨 아래 줄은 **미**, 그 위 칸은 **파**, 그 위 줄은 **솔**입니다.
- 맨 아래 줄 밑의 칸은 **레**, 그 아래에 짧은 덧줄을 그은 음은 **가운데 도**입니다.
- **도 → 미**는 덧줄의 도에서 레가 있는 칸을 거쳐 맨 아래 줄의 미로 올라갑니다.
- **도 → 솔**은 도·레·미·파·솔 다섯 자리를 셉니다.

위 그림의 왼쪽에서는 음을 따로 보여 간격을 셉니다. 오른쪽에서는 **도·미·솔을 세로로 쌓아 동시에 울리는 C 코드**를 보여 줍니다. 보라색은 근음, 파란색은 3도 음, 초록색은 5도 음입니다.

> **근음은 코드의 기준이 되는 음입니다. C의 근음은 도(C), Am의 근음은 라(A)입니다.** 근음은 ‘으뜸음(조성의 중심음)’과 구별하며, 실제 연주에서 항상 가장 낮게 울려야 하는 것도 아닙니다. 이 그림은 근음이 맨 아래에 놓인 기본 위치로 설명합니다.

### 2-2. 왜 그냥 ‘3도’가 아니라 ‘장3도’일까요?

**음 이름을 세면 ‘몇 도인지’가 정해지고, 실제 반음 간격을 확인하면 ‘장·단·완전’ 등의 종류가 정해집니다.** 같은 3도라도 장3도와 단3도는 소리의 거리가 다릅니다.

**반음**은 피아노에서 바로 옆 건반까지의 간격입니다. 흰건반과 검은건반을 모두 포함해서 셉니다. 기타에서는 **같은 줄의 바로 옆 프렛까지가 반음**입니다. **온음은 반음 두 개**입니다.

자연음 사이에서 **미–파, 시–도는 반음**, 그 밖의 인접한 자연음 **도–레, 레–미, 파–솔, 솔–라, 라–시**는 온음입니다.

| 비교 | 음 이름으로 세기 | 실제 거리 계산 | 이름 |
| --- | --- | --- | --- |
| 도 → 미 | 도(1)·레(2)·미(3) → 3도 | 도→레 2반음 + 레→미 2반음 = **4반음** | **장3도** |
| 도 → 미♭ | 도(1)·레(2)·미♭(3) → 3도 | 도→미 4반음에서 미를 반음 내림 = **3반음** | **단3도** |
| 도 → 솔 | 도(1)·레(2)·미(3)·파(4)·솔(5) → 5도 | 2 + 2 + 1 + 2 = **7반음** | **완전5도** |

**♭(플랫)**은 해당 음을 반음 낮추고, **♯(샤프)**는 반음 높입니다. 미에 ♭이 붙어도 음 이름의 기준은 ‘미’이므로 도–미♭ 역시 3도입니다.

여기서 반음 수는 **출발 음을 0으로 두고 이동한 횟수**를 셉니다. 앞에서 출발 음을 1로 센 ‘몇 도인지’와 세는 방식이 다릅니다.

- **도 → 도♯ → 레 → 레♯ → 미**: 이동 4번이므로 **4반음**입니다.
- **도 → 도♯ → 레 → 레♯ → 미 → 파 → 파♯ → 솔**: 이동 7번이므로 **7반음**입니다.

따라서 C의 **도·미·솔**에서 **도는 근음, 미는 도보다 장3도 위, 솔은 도보다 완전5도 위**입니다.

### 2-3. ‘완전5도’의 ‘완전’은 무슨 뜻인가요?

‘완전’은 좋고 나쁨을 평가하는 말이 아니라 **음정의 종류를 나타내는 이름**입니다. 기초 이론에서 **1·4·5·8도는 완전 계열**, **2·3·6·7도는 장·단 계열**로 구분합니다. 증·감음정은 그 간격을 더 넓히거나 좁힌 경우입니다.

즉, 3도에는 ‘장3도·단3도’가 있고, 5도의 기준 간격에는 ‘완전5도’라는 이름을 씁니다. **위로 세는 5도이면서 거리가 7반음일 때 완전5도**입니다.

**아무 5도나 모두 완전5도인 것은 아닙니다.** 예를 들어 시–파는 시(1)·도(2)·레(3)·미(4)·파(5)로 5도지만, 거리는 6반음이어서 **감5도**입니다.

### 2-4. Am의 라·도·미도 같은 방법으로 확인하기

Am의 기준음은 도가 아니라 **라**입니다. 라를 출발점으로 다시 1부터 셉니다. 아래 그림의 라는 오선지 둘째 칸, 도는 셋째 칸, 미는 넷째 칸에 있습니다.

| C 마이너(Cm) | 도·미♭·솔 | 도→미♭ **3반음(단3도)** | 도→솔 **7반음(완전5도)** |
| A 메이저 | 라·도♯·미 | 라→도♯ **4반음(장3도)** | 라→미 **7반음(완전5도)** |
| A 마이너(Am) | 라·도·미 | 라→도 **3반음(단3도)** | 라→미 **7반음(완전5도)** |

**같은 근음의 메이저와 마이너 3화음은 가운데의 3도 음이 반음 차이 납니다.** C에서 미를 반음 내리면 Cm, A에서 도♯을 반음 내리면 Am입니다.

### 2-5. ‘장3도·완전5도’와 ‘3도를 두 번 쌓기’의 차이

**근음·장3도·완전5도**라고 할 때는 두 간격을 **모두 근음에서** 잽니다. C 코드에서 도→미가 장3도이고 도→솔이 완전5도라는 뜻입니다.

인접한 구성음끼리 재면 도→미는 장3도(4반음), 미→솔은 단3도(3반음)입니다. 두 간격을 더한 도→솔이 7반음입니다.

- **메이저 3화음:** 아래에서부터 **장3도 + 단3도**를 쌓음 → 근음 기준 **0·4·7반음**
- **마이너 3화음:** 아래에서부터 **단3도 + 장3도**를 쌓음 → 근음 기준 **0·3·7반음**

**장3도 위에 다시 완전5도를 쌓는다는 뜻은 아닙니다.** ‘근음에서의 간격’과 ‘이웃한 구성음 사이의 간격’을 구별하세요.

### 2-6. 기타에서는 왜 다섯 줄·여섯 줄을 치나요?

앞서 소개한 C 운지 **x32010**을 치면 5번 줄부터 **도–미–솔–높은 도–높은 미**가 울립니다.

| 치는 줄 | 울리는 음 | C 코드에서의 역할 |
| --- | --- | --- |
| 5번 줄 3프렛 | 도(C3) | 근음 |
| 4번 줄 2프렛 | 미(E3) | 장3도 음 |
| 3번 줄 개방 | 솔(G3) | 완전5도 음 |
| 2번 줄 1프렛 | 높은 도(C4) | 근음의 한 옥타브 위 음 |
| 1번 줄 개방 | 높은 미(E4) | 장3도 음의 한 옥타브 위 음 |

숫자 C3·C4 등은 **실제 소리의 옥타브 높이**를 나타냅니다. 도와 높은 도는 높이는 다르지만 같은 이름의 음이므로, C 코드는 다섯 줄을 쳐도 **도·미·솔 세 종류의 음**으로 이루어집니다.

Em의 **022000**은 여섯 줄에서 **미–시–미–솔–시–미**가 울리지만 구성음은 **미·솔·시** 세 종류입니다.

위의 오선지 그림은 **음정 원리를 설명하기 위한 높이**로 그렸습니다. 실제 기타 C 운지의 음 높이를 그대로 옮긴 악보는 아닙니다. 일반적인 기타 오선보는 실제 소리보다 한 옥타브 높게 적는 관례도 있습니다.

### 직접 확인하기

1. 도에서 미까지 **도(1)·레(2)·미(3)**를 세어 3도임을 확인합니다.
2. 도→레가 2반음, 레→미가 2반음이므로 **장3도**임을 확인합니다.
3. 도→솔은 5도이면서 7반음이므로 **완전5도**임을 확인합니다.
4. 라→도는 3도이면서 3반음이므로 **단3도**임을 확인합니다.

> **먼저 음 이름으로 몇 도인지 세고, 그다음 반음 수로 장·단·완전 등의 종류를 확인합니다.**


## 3. 코드표 읽는 법

아래 그림은 기타 지판을 정면에서 본 모양입니다. **왼쪽이 6번 줄, 오른쪽이 1번 줄**, 위쪽 굵은 가로선이 **너트**, 그 아래 칸이 1·2·3·4프렛입니다.

| 표시 | 의미 |
| --- | --- |
| 세로선 6개 | 기타의 여섯 줄 |
| 가로선 | 프렛의 경계 |
| 파란 원 | 왼손으로 누를 위치 |
| 원 안의 1·2·3·4 | 검지·중지·약지·새끼손가락 |
| 위쪽 ○ | 누르지 않고 울리는 개방현 |
| 위쪽 × | 치지 않는 줄 |
| 그림 아래 6·5·4·3·2·1 | 줄 번호 |

### C 코드를 실제로 잡아 보기

1. 검지로 **2번 줄 1프렛**을 누릅니다.
2. 중지로 **4번 줄 2프렛**을 누릅니다.

4. 6번 줄을 피하고 5번 줄부터 1번 줄까지 한 줄씩 튕깁니다.
5. 모든 음이 또렷하면 천천히 쓸어 내려 함께 울립니다.

손끝을 세워 옆줄을 건드리지 않게 하고, 엄지는 지판 뒤에서 편하게 받칩니다. 줄이 울리지 않으면 더 세게 누르기 전에 손가락 위치와 옆줄 접촉을 확인하세요.

## 5. F 코드와 바레 코드

**바레(바)**는 한 손가락으로 여러 줄을 동시에 누르는 방식입니다. F 메이저의 대표적인 운지는 **133211**입니다.

| 손가락 | 누르는 위치 |
| --- | --- |
| 검지 | 1프렛에서 6개 줄을 가로질러 누름 |
| 중지 | 3번 줄 2프렛 |
| 약지 | 5번 줄 3프렛 |
| 새끼손가락 | 4번 줄 3프렛 |

이 모양으로 여섯 줄을 울리면 F의 구성음인 **파·라·도**가 나옵니다. 처음부터 전체 바레가 어렵다면 **xx3211**의 작은 F를 연습할 수 있습니다. 이때 검지로 1·2번 줄 1프렛, 중지로 3번 줄 2프렛, 약지로 4번 줄 3프렛을 누르고 **4번 줄부터** 칩니다.

**Fmaj7(x33210 등)은 F와 다른 코드**입니다. 쉬워 보인다고 모든 곡에서 F 대신 바꿔 쓰면 화음이 달라집니다. 먼저 작은 F로 구성음을 유지하며 연습해 보세요.

## 6. 소리가 탁하거나 끊길 때

| 들리는 문제 | 먼저 확인할 점 |
| --- | --- |
| 특정 줄이 전혀 안 울림 | 손가락 옆면이 이웃 줄을 막고 있는지 확인 |
| 지직거리는 소리 | 손끝을 프렛 막대 뒤쪽으로 조금 옮기고 필요한 만큼 누르기 |
| C·D 코드가 둔탁함 | 치지 않아야 할 낮은 줄까지 치고 있는지 확인 |

| 손목이 불편함 | 손목을 과하게 꺾지 않도록 자세를 바꾸고 쉬기 |

처음에는 여섯 줄을 한꺼번에 세게 치기보다 **정해진 시작 줄부터 한 줄씩** 점검하면 원인을 찾기 쉽습니다.

## 7. 코드 전환과 리듬 연습

아래 진행은 연습용입니다. 세로선 한 칸을 **4박자 한 마디**로 보고 각 박마다 한 번씩 아래로 내려칩니다.

| 단계 | 코드 진행 | 연습 목표 |
| --- | --- | --- |
| 1 | Em → Am → Em → Am | 손가락 두세 개를 정확히 옮기기 |
| 2 | G → D → Em → C | 서로 다른 시작 줄에 맞춰 스트로크하기 |
| 3 | C → Am → Dm → G | 메이저·마이너 소리와 전환 익히기 |
| 4 | C → G → Am → F | 작은 F 또는 전체 F로 연결하기 |

**스트로크**는 여러 줄을 쓸어 치는 동작입니다. 처음에는 “하나, 둘, 셋, 넷”을 말하며 각 박에 한 번 내려치세요. 코드가 바뀌어도 오른손 박자를 유지할 수 있는 느린 속도에서 시작합니다.

익숙해지면 한 박을 **‘하나 앤, 둘 앤, 셋 앤, 넷 앤’**으로 나누고 숫자에서는 내려치기, ‘앤’에서는 올려치기를 연습합니다. 빠르게 치는 것보다 일정한 간격을 유지하는 것이 먼저입니다.

### 하루 10분 연습 예시

1. **1분:** 튜닝을 확인합니다.
2. **3분:** Em·Am·C를 잡고 한 줄씩 소리를 확인합니다.
3. **3분:** 두 코드를 골라 4박자씩 번갈아 연주합니다.
4. **2분:** G–D–Em–C를 일정한 박자로 연결합니다.
5. **1분:** 잘 안 울린 줄과 어려운 전환을 기록합니다.
